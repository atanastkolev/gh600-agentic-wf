## Recent GitHub updates

Updated 2026-11-09.

- **Actions: `pull_request_target` blocked by default on December 2, 2026.** In public repositories, GitHub Actions will block `pull_request_target` events unless an Actions event policy explicitly allows them. Review your workflows now. ([GitHub Changelog](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2))
- **Copilot: @GitHub in Slack and Teams is generally available.** Investigate bugs, create issues, implement changes, and open pull requests from a chat conversation. ([GitHub Changelog](https://github.blog/changelog/2026-11-06-github-copilot-in-slack-and-teams-is-generally-available))
- **Pull requests: new overview page in public preview.** Check what is blocking a long pull request without scrolling through comments and timeline events. ([GitHub Changelog](https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview))
- **Copilot: now in JetBrains Air and Xcode's coding assistant.** More editors, same assistant. ([JetBrains Air](https://github.blog/changelog/2026-11-03-github-copilot-is-now-available-in-jetbrains-air), [Xcode](https://github.blog/changelog/2026-11-04-github-copilot-is-now-available-in-xcodes-coding-assistant))
